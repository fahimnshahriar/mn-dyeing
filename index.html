Dyeing Process Sheet Printer

Type the MC number: MC 1-23 opens Unit 1 and MC 101-106 opens Unit 2 automatically, and the process number is searched in that unit's own process folder. Then enter the process number, GSM and dia, then press Print. The sheet below is exactly what prints.

1. Print one machine

L/W = GSM x dia(inch) x 0.0254. R/L = load kg x 1000 / (L/W x nozzles). Reel speed = R/L / cycle time. If Load kg is empty the machine capacity is used; if L:R is empty the machine's minimum water is used. Levelling water (tick "Show levelling water" to print it) = total liquor - (tank fills x tank size) - (load x absorbency), same as RECIPE_CALCULATOR.xlsx. Unit 1 and Unit 2 each remember their own last entry. Keys: Enter, Down or Right arrow = next field; Up or Left arrow = previous field; Ctrl+Enter = print.
